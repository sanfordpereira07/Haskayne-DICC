# Constellation: demo video script (about 1:45)

Voiceover plus click-through for the screen recording. The path runs from candidate to recruiter and
ends on the recruiter's decision. Speaking pace is about 150 words per minute. Times are targets, and
your clicks fill the pauses between spoken lines.

## Before you hit record

1. Open the app full screen at 16:9 (1920×1080 is ideal). Hide bookmarks and extra tabs.
2. Click **Reset demo** (top right). Check that the **Candidate** switch is selected and no category
   star is open.
3. If you used **Edit name**, replace "Maya" in the script with your name. Do this *before* recording.
   Don't reload the page between takes if you're using the hosted copy.
4. Do one dry run. Move the cursor slowly, and pause for a beat after each click so the quick
   transitions can settle.
5. Use **Reset demo** between takes. It keeps your name.

## Timing and trims

- **Planned length:** about 1:45, with the last few seconds as a silent hold. At a slower 140 words per
  minute it runs about 1:50.
- **If you run over 1:50, cut in this order:**
  1. Drop the **Tailor for this role** beat (saves about 5 seconds).
  2. Shorten the Role criteria line to a click with no narration (about 4 seconds).
  3. Drop "prioritized by AI-assisted match" from the 1:05 line (about 3 seconds).
- **If you run under 1:30:** slow down on the recruiter panel (1:22 – 1:36). It's the most important
  moment.

## Click map (15 clicks, no typing)

Extracurriculars → Hobbies & Interests → Continue application → Choose (Adaptability) → Garden Lead →
Tailor → Done → Choose (Stakeholder communication) → Gaming Organizer → Attach sample file → Submit
application → Recruiter → Role criteria → Maya's row → Shortlist for interview
